# Демонстрация портфолио за 10–15 минут

## 1. Кратко представить задачу

«Я сделал три небольших API и разделил бизнес-правила, сценарии, доступ к данным и HTTP. Самые интересные места — параллельные заказы, месячная аналитика и SLA, которое определяется данными».

## 2. StockFlow: показать проблему конкуренции

Создайте товар с остатком 5, закажите 3 единицы, повторите заказ на 3: ответ 409, остаток 2. Отмените первый заказ: остаток 5. Повторная отмена возвращает 409. Покажите транзакцию и условный ExecuteUpdate в EfStore. Объясните, почему обычная последовательность «прочитал остаток → проверил → сохранил» без защиты допускает overselling.

В тестах есть параллельные заказы на последнюю единицу; этот сценарий выполняется на PostgreSQL в CI, а локально без PostgreSQL отмечен как пропущенный.

## 3. ExpenseLens: показать запрос и границы месяца

Создайте категории с бюджетом и расходы в соседних месяцах. Получите отчёт: только расходы нужного месяца, пустые категории с нулём, отрицательный Remaining при превышении бюджета. Покажите LINQ-проекцию, SQL-агрегат и составной индекс. Объясните выбор decimal и DateOnly.

## 4. SupportDesk: показать правила и конфликт обновления

Добавьте произвольный приоритет с SLA 90 минут. Создайте обращение с этим приоритетом: срок появится без изменения кода. Переведите его в InProgress, сохраните новую Version. Запрос с прежней Version должен вернуть 409. Завершите обращение с актуальной Version. Объясните различие проверки версии до записи и EF concurrency token во время UPDATE.

## 5. Показать проверку и ограничения

Откройте тесты, миграции и GitHub Actions. Разделяйте то, что проверено локально, и то, что выполнит CI после публикации репозитория. Назовите границы: нет пользователей и платежей, одна валюта, один товар на заказ. Возможные следующие задачи: JWT/роли, pagination для всех коллекций, идемпотентность заказов, история бюджетов и SLA, наблюдаемость.

Для резюме после самостоятельного изучения кода:

> Разработал три REST API на C#/.NET с разделением Domain/Application/Infrastructure/API. Реализовал EF Core и PostgreSQL, транзакционное резервирование остатков, SQL-аналитику расходов, data-driven SLA и optimistic concurrency. Подготовил миграции, Docker Compose и интеграционные тесты с CI.
